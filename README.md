# os-notes

操作系统学习笔记与实践代码。

## 目录规划

> 目前仓库是空的，按需往下面这些目录里放内容即可。

| 目录 | 用途 |
| --- | --- |
| `notes/` | 读书笔记、课程笔记（Markdown） |
| `lab/` | 课程实验：代码、报告、运行结果 |
| `src/` | 自己写的内核 / 驱动 / 汇编练习 |
| `books/` | 各本书的章节目录、习题、勘误 |
| `tools/` | 构建脚本、QEMU 启动脚本、调试配置 |

## 笔记约定

- 一篇笔记一个 Markdown 文件，文件名用 `章节_主题.md`
- 代码块标语言：`c` / `asm` / `makefile` / `bash`
- 踩坑记录写进 `notes/踩坑记录.md`，注明现象、原因、解决办法
